# Agent Instructions

This repository contains a self-contained Vue.js + Three.js 3D cube demo built with Vite. The project demonstrates 3D rendering using Three.js within a Vue component.

## Key Commands
- `npm run dev` - Start development server (host: 0.0.0.0, port: 3000)
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally

## Project Boundaries
- Entry point: `main.js`
- Main component: `App.vue`
- HTML template: `index.html`
- Vite configuration: `vite.config.js`

## Conventions
- Uses Vue 3 Composition API
- Uses Three.js for 3D rendering
- All code is contained in this single directory
- No external dependencies beyond Vue and Three.js
- No CI/CD or Docker configurations present

## Development Environment
- Host: 0.0.0.0
- Port: 3000
- Framework: Vue 3 + Vite
- 3D Library: Three.js

## Dependencies
- Vue 3 (via @vue/runtime-core)
- Three.js (via three)

## Notes
- This is a minimal, self-contained demonstration
- No build tooling or infrastructure beyond what's specified
- All code is expected to be in this directory
